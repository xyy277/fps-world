- 换弹动画：枪身下沉旋转 + 弹药计数
- 弹壳抛出

### P1B：武器扩展
- commit：`5c07039`
- 手雷（G 键 / 触屏「雷」按钮）：抛物线物理 + 落地引爆
- 近战（V 键 / 触屏「刀」按钮）：扇形命中 + 冷却

### P2：敌人 AI 升级
- commit：`e69e834`
- FSM 状态机：追击 / 攻击 / 逃跑 / 游荡
- A* 寻路：10×10 网格 + 500 迭代上限
- 掩体利用 + 玩家速度预判

### P3：战斗 UI 与反馈
- commit：`221230d`
- 伤害数字：DOM 池 + 3D→2D 投影 + 上浮淡出，爆头金色/暴击红色
- 小地图：Canvas 2D，每 3 帧刷新，显示玩家视野/敌人/掉落
- 击杀提示（Killfeed）：限定 5 条，自动淡出
- 计分板：武器分布 + 爆头数 + 最高连杀
- 设置面板：画质 / 音量 / 灵敏度，localStorage 记忆

### P4：存档与进度系统
- commit：`f58e8b3`
- localStorage 全局存档：最高分/最高波次/总击杀/总局数/总爆头/最佳连杀
- 12 项成就：局内实时检测 + Toast 通知 + 成就墙
- XP / 等级 / 技能点：升级公式 `lv * 100`，击杀 +10xp、每波 +20xp
- 升级树：4 项属性（伤害/血量/换弹/移速）各 5 级，玩法实际生效
  - dmgMul：子弹 + 近战伤害 +10%/级
  - reloadMul：装填时间 -10%/级
  - speedMul：移速 +8%/级
  - maxHp：最大生命 +15/级（替代硬编码 100）
- UI 入口：菜单 / 暂停 / 游戏结束界面均加入「进度」「升级」按钮
- HUD 等级条：经验进度，避开热键栏

### P5：沉浸感增强
- commit：`21b4b17`
- 程序化 BGM：三段循环旋律（menu 80bpm 三角波 / battle 140bpm 方波 / over 60bpm 正弦），Oscillator+GainNode 序列播放，状态机自动切换
- 默认静音 + 设置面板扩展：5 开关（静音/BGM/天气/纹理/后处理），localStorage 记忆，首次进入无声避免惊吓
- 天气系统：雨/雪 Points 粒子，跟随玩家，与昼夜联动随机切换，画质分级控制粒子数（low=0/mid=300/high=700）
- 后处理泛光：用 r128 内置 ACESFilmic toneMapping 近似，零额外依赖；纹理开关→纯色降级
- 教程引导：首次开始游戏显示操作指引（PC/触屏双版本），6 秒淡出，localStorage 记忆
- 首次交互启动音频：浏览器策略合规（pointerdown/keydown once）
