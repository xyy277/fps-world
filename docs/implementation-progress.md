## 4. 后续目标（按优先级收敛）

### 4.1 P6 剩余：内容扩展收尾

| 编号 | 功能 | 说明 | 依赖 | 优先级 |

### 4.2 操作手感优化（独立小节，可穿插）

| 功能 | 当前 | 建议改为 | 优先级 |
|------|------|---------|--------|
| 右键 | 放置方块 | **ADS 瞄准射击**（所有武器右键开镜，FOV 75→45，散布减半） | 🔴 高 |
| 建造方块 | 右键 | 改为 **E 键** 或 **鼠标中键**，1-6 仍选方块类型 | 🔴 高 |
| F 键 | 狙击镜 | 保留（狙击专属高倍镜，FOV→15） | — |
| G 键 | 手雷（3 颗，掉落补充） | 维持现状，HUD 已显示数量 | — |

> 理由：右键 ADS 是现代 FPS 标配，当前仅狙击枪有开镜，体验割裂。改键后操作符合玩家肌肉记忆，建造功能不丢。

### 4.3 P7：画质增强（程序化路线，不引入素材）

| 功能 | 说明 | 收益 | 优先级 |
|------|------|------|--------|
| 光照升级 | DirectionalLight + ShadowMap + 暖色调 HemisphereLight | 接近 AI 概念图氛围 | 🔴 高 |
| 雾化纵深 | Fog 参数调优 + 远景层次 | 氛围感 | 🔴 高 |
| 植被 InstancedMesh | 草丛/小石头批量渲染，零开销 | 场景密度 | 🟡 中 |
| SSAO 后处理 | EffectComposer + 环境光遮蔽 | 质感提升 | 🟡 中 |
| 纹理细化 | Canvas 2D 加噪声/划痕/污渍 | 材质细节 | 🟡 中 |
| 粒子优化 | 雨/雪用 Sprite + AdditiveBlending，带辉光 | 特效质感 | 🟢 低 |

> 目标：在不破坏「单文件、零素材」铁律下，画质接近 AI 概念图 80% 水平。剩余 20% 需真实素材，不做。

### 4.4 P8：多场景 / 关卡随机组合

| 功能 | 说明 | 依赖 |
|------|------|------|
| 场景切换器 | 关卡间过渡 UI + 状态重置 | P6 完成 |
| 多 biome 地形 | 沙漠 / 雪原 / 森林 / 废墟，程序化生成 | P0 |
| 难度递进曲线 | 每关敌人配比 / Boss 节奏 | P6.3 |
| 关卡间奖励 | 通关回血 / 选 buff / 武器解锁 | P4 |

> 工作量较大，P8 规划合理，P6/P7 不碰。

### 4.6 技术债务

- **单文件体积**：当前 2677 行，P6-P9 完成后预计 3500-4000 行，仍在可控范围。
- **区段冲突**：多 Agent 改同文件需严格串行 + re-read。
- **移动端性能回归**：新增渲染逻辑需在低画质档验证 draw call 与粒子数。
- **存档兼容**：`SAVE_KEY = "fk_save_v1"`，后续若结构变更需写迁移逻辑。
- **README 截图**：当前为 AI 概念图（hero-banner.jpg / night-combat.jpg），非真实游戏截图。P7 画质完成后可替换为真实截图。
